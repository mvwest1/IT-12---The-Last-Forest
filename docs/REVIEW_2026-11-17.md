# Review of the 2026-11-16 outside-agent edits (Antigravity)

Every change was checked against the code, the tests and the Godot/OOXML rules. Kept items were merged; rejected items were replaced. Regression tests for the rejected items are in `tests/production_test.gd` ("Regression guards").

## Rejected (bugs or problems)
| # | Problem | Why it matters | What v1.0.0 does |
|---|---|---|---|
| 1 | Five invented learners ("Lunti", "Tala", "Mateo", "Mayumi", "Kiko") hard-coded into the leaderboard | Fabricated records inside a research instrument; a panel member who asks "who is Tala?" ends the credibility of the data | Leaderboard shows only real learners from the database; empty database = empty board |
| 2 | Learner's first name stored in `students.name` and shown on the leaderboard | Breaks the RA 10173 design (names of minors were never stored) | Name never stored; optional cleaned nickname (12 chars) or "Ranger #XXXX" code |
| 3 | `window/handheld/orientation=1` described as "landscape lock" | 1 = **portrait** in Godot; the platformer would open sideways on phones | 4 = sensor landscape |
| 4 | Backup-journal write returned "saved" even when the file could not be written | Hides data loss and disables the Retry Save safety net | Original behaviour kept: failure is reported, Retry Save appears |
| 5 | Missing SQLite shown as "Database: local storage active" and described as an Android "dual engine" | SQLite was simply not packaged for Android; the label hid it | Android arm64 SQLite library packaged; label still says honestly when the add-on is missing |
| 6 | Eco-Score rewarded pre-to-post gain (+50 per point) | A child scores more by failing the pre-test on purpose: damages the research data | Forest Points never use the pre-test |
| 7 | Both .docx files were zipped with backslash paths (`word\document.xml`) | Not valid OOXML; Word may refuse to open them or report unreadable content | Documents rebuilt from the original draft with standard paths; verified by opening and converting to PDF |
| 8 | Defense guide claims that were false (portrait called landscape, JSONL "dual engine", sample players) | The panel can check them in the code | New guide written against the final code |
| 9 | `player/robot.webp` overwritten by a front-facing character; Android icons pointed at a 128 px image | Original demo asset lost; blurry launcher icon | Original restored; side-view Eco-Ranger in `art/ranger.png`; 192 px and 432 px adaptive icons |
| 10 | AI-assistance line deleted from README | The course requires AI tools to be cited | Declaration restored and updated |
| 11 | "❚❚ Pause" text button | The pixel font has no ❚ glyph (shows as boxes) | Icon-based touch pause button |
| 12 | Runtime CSV re-parsing of translations added on top of the imported ones | Duplicate translations, unescaped text | Removed; imported translations only |

## Kept (good ideas, merged)
- Hide the touch buttons while the game is paused.
- Remove the highlight from a sapling once it is a grown tree.
- Close the database if table creation/migration fails, so writes go to the backup instead.
- `*.apk`, `*.aab` in `.gitignore`; removal of the unused `addons/ziva_agent`.
- Correcting the manuscript's registry tables to real project paths, and adding asset pictures to 3.2 (redone with the final art).
